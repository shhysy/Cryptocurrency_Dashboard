# 自动化交易落地路径（本地优先）

> 策略规则唯一依据：根目录 `策略3.3.xlsx` 与用户确认决策。本文只谈工程落地，不改策略参数。

## 目标形态

1. **看板（Next.js）**：只读展示信号、持仓、成本；本机 `npm run dev` 运行。  
2. **常驻执行器（规划）**：`npm run trader`（GPT 主责）在无浏览器时跑节拍、对账、恢复。  
3. **存储**：本机持久化（规划 `lib/execution/server/` + `data/`），不再以 Cloudflare Durable Object 为部署目标。  
4. **交易所**：Spot Testnet 先行；生产 BUY/SELL、Simple Earn 真实赎回默认关闭，须用户明确授权。

## 阶段概览

| 阶段 | 内容 | 主责 |
|------|------|------|
| M0 | 清理 CF 部署依赖、修 SELL 01A、文档本地化 | GPT + Grok |
| M1 | 本地存储接口、常驻进程、SELL 适配器 | GPT 主、Grok SELL |
| M2 | Testnet BUY/SELL 实测 | GPT 主、Grok 复核 |
| M3 | 自检、熔断、通知、Earn | 双方 |

## 节拍与调度

- 推荐：本机常驻进程定时拉信号、跑节拍；**不依赖 Cloudflare**。  
- 结果不明订单：按 `clientOrderId` 只读查单，禁止盲目重发。  
- 生产开关与 Testnet 开关完全隔离。

## 安全红线

- 不得使用真实 Key 做自动化测试冒充 Testnet。  
- 不得把单元测试说成 Testnet 验收。  
- 策略参数变更必须走 Excel 与用户确认决策，不得在代码中偷偷改档位。
