## 止盈比例口径补充（2026-11-20）

用户明确确认：止盈比例采用**本轮初始周期仓**作为统一基数，而不是每次按剩余周期仓重复计算。

以初始周期仓100个币为例：
- 止盈1目标：50个（初始周期仓的50%）。
- 止盈2目标：30个（初始周期仓的30%）。
- 止盈3目标：80个（初始周期仓的80%），但前两档已累计卖出80个，因此本档最多卖出剩余20个。
- 三档合计最多卖出本轮初始周期仓的100%；任何情况下不得卖穿底仓或卖超当前剩余周期仓。
