# 策略3.3规则手册

> 唯一权威来源：用户于2026-11-19确认的《长期投资策略V3.2_优化版_V3.3(1).xlsx》。项目统一称《策略3.3》。本手册为文字索引，不替代工作簿公式与单元格。

## 1. 策略定位与纪律
- 研究与决策辅助；只做现货、不加杠杆、不自动下单。
- 参数为经验假设，未经回测；回测及样本外验收通过前不得实盘。
- 「交易日志」是唯一真实成交数据源。只有确认成交可改变持仓、均价、已成交档位、现金及已执行止盈/减仓。
- 极端风险否决、白名单审核、基本面清单、持仓后最高周收盘价、最新周收盘价、历史净值峰值、初始资金/追加入金由人工维护。
- 周线未收盘、数据缺失或来源不一致时，数据完整性为“否”，不能产生有效买入许可。

## 2. 资产形态
资产池类别为核心使用积极型，类别为山寨使用保守型；ETH默认核心，用户可在资产池调整。山寨白名单审核包括上市年限、市值排名、流动性、解锁、开发活跃度及交易所风险；山寨需定期复审。基本面失效项包括项目停更/团队解散、下架或流动性枯竭、重大安全事件未解决、30天内大额解锁、监管法律重大风险、竞争力或需求持续恶化。

## 4. 评分与企稳
总分=价格位置≤45 + 情绪≤30 + 趋势结构≤15 + 可选成交量≤10；成交量关闭时最高90。价格位置按RSI与价格/周线MA200两项较高者加较低者×0.5，封顶45；趋势结构=企稳项数×5。企稳三项：
1. 本周已收盘价高于上周最高价；
2. RSI低于45且较上周回升；
3. 近4周未创此前8周新低。
买入分数及企稳项数按积极/保守形态门槛执行。

## 5. 市场与组合风控
BTC熊市：周收盘低于MA200且MA200下行；牛市：收盘≥MA200且MA200不下行；其余过渡市。人工极端风险否决为“是”时所有币禁止新增。
- 买后现金≥净值30%；
- 山寨成本≤净值10%；BTC+ETH核心成本≤净值25%；
- 山寨持仓达到3个后不再新开；
- 近7天新增买入成本≤净值5%；
- 回撤15%新增金额减半；回撤25%暂停所有新增；
- 交易日志异常行数>0禁止买入；
- 数据、白名单、基本面、分数、企稳、市场、冷却、现金、单币/组合/单周额度均需通过。

## 6. 建仓、补仓与备用金
头仓、补仓、备用金均为信号/建议，不等于自动成交。补仓按头仓真实成交基准，条件不满足不跳档，上涨不追加，亏损本身不是补仓理由。备用金需达到相对头仓跌幅、极度恐惧条件及至少2项企稳条件。档位完成只以交易日志确认成交为准。

## 7. 持仓与卖出
- 底仓按累计买入量×形态底仓比例锁定，并扣除已减仓量；其余为周期可卖仓。
- 指标止盈：RSI>75或恐惧贪婪≥80进入检查，价格高于均价；每次卖周期可卖仓25%，间隔至少2周，累计不超过累计周期仓50%。
- 底仓减仓：价格≥均价×3、RSI≥80且情绪同时过热；计划减仓50%，一次性。
- 追踪止损按周线收盘价判断，积极型1.3倍/30%，保守型1.2倍/20%。
- 基本面失效：核心≥2项、山寨≥1项；极端风险退出人工复核，不自动给数量。
- 浮亏本身不自动卖；浮亏达到50%且BTC熊市时提示复核。
- 清仓后重置补仓档位，冷却4周后再按新信号开头仓。

## 8. 回测验收
积极型建议回测2018-01至2025-12；保守型2019-01至2025-12并包含存活及退市样本。样本外留最后12–18个月；压力测试2018熊、2020–21牛、2022熊、2023–25、闪崩、退市归零和流动性枯竭。扣除手续费滑点，做1×/1.5×/2×成本敏感性。指标包括年化收益、最大回撤、夏普、Calmar、交易次数、现金闲置比例、风控触发次数及触发后90/180/365天收益；与定投和买入持有比较，计入现金闲置机会成本。未通过数据质量、样本外和风险验收不得实盘。
