### 必须交用户确认的策略差异（本轮不改代码/Excel）

1. **C2评分具体分值：** Excel「参数中心」MA五档为30/25/20/15/10，F&G分档为30/25/20/15（阈值10/20/30/40）；当前 `strategy.config.ts` MA为30/24/18/12/6，F&G为30/25/20/10/5（阈值10/15/25/35/40）。用户确认C2是“保留代码五档细化评分”，但没有在决策文件中逐项列明最终分值；需确认是以当前代码五档为准，还是以工作簿现有五档数值为准。
2. **备用金极度恐惧线：** Excel参数中心将F&G阈值1=10作为极度恐惧线；当前代码 `extremeFear=25`。需确认最终阈值。
3. **追踪止损峰值口径：** Excel写明维护“持仓后最高周收盘价”，并按周收盘判断；当前引擎使用持仓后的周线high及当前price。需确认要不要改为周收盘价口径。
4. **企稳/市场状态触发价格：** Excel以本周周线收盘价定义“本周收盘>上周最高”及BTC市场状态；当前引擎部分函数接收 `input.price` 作为实时价格。需确认自动执行信号只在周线收盘后触发，还是允许周内实时价触发。
5. **G2执行许可：** 用户决策明确展示层允许STALE软失败，但执行许可需单独评估；当前Trader遇到STALE会跳过新订单。暂时保持fail-closed，等待确认，不放宽。
