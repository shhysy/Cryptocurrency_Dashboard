4. **企稳/市场状态触发价格：** Excel以本周周线收盘价定义“本周收盘>上周最高”及BTC市场状态；当前引擎部分函数接收 `input.price` 作为实时价格。需确认自动执行信号只在周线收盘后触发，还是允许周内实时价触发。
