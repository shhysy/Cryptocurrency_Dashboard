## P0差异与风险
1. 旧代码曾统一使用2/3/5倍止盈及50/30/80比例，与策略3.3积极/保守型不同参数冲突。
2. 现金30%、山寨10%、核心25%、单周5%、回撤15%/25%等组合约束，若无法获得可信净值/峰值必须阻断相关买入，不得声称已实现。
3. 周度评分只允许已收盘周线；实时ticker不得替换周线close。建议分离signalAsOf与executionPrice。
4. 备用金企稳条件以V3.3参数备注“至少2项”为准；工作簿其他旧提示如仍写3项，应登记并更新，不能误用旧值。
5. 交易日志是真实成交唯一真源；计划单、预备订单、未成交订单及CSV意向记录不得改变持仓。

每项差异需记录工作表/单元格或原文、代码位置、影响场景、修复方案、测试、风险与回滚。未经用户确认不得改变策略参数。
