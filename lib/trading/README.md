# 交易执行内核（原型，暂不接入页面）

`lib/trading/` 是早期通用执行内核原型，包含纯函数规划与 IndexedDB 存储示例。当前 Dashboard 尚未导入此目录，**不要将它视为已启用的自动交易链路**。

项目后续统一以 `lib/execution/` 作为 V3.3 策略执行模块的开发入口，避免两套订单队列、成交台账和 IndexedDB 数据库并行运行。这里的代码暂时保留用于参考与测试；在完成迁移或删除前，不要从 UI 同时调用两个目录。

## 原型覆盖范围

- USDT 余额与单币成本上限下的买入金额规划。
- LOT_SIZE 数量步长、最小数量和最小名义金额预检。
- 周期仓与长期底仓数量保护。
- 策略事件幂等键、订单状态和累计成交单调性。
- IndexedDB 订单、执行记录、成交台账与 CSV 导出原型。

## 当前限制

- 没有 Binance 下单或撤单请求。
- 没有自动订单轮询与完整成交对账。
- 没有接入 V3.3 策略引擎或 Dashboard UI。
- 没有买卖邮件通知联动。
- 没有运行 Testnet 或真实交易。

当前执行层进展与后续工作以仓库根目录 `AUTO_TRADING_DESIGN.md` 和 `lib/execution/PHASE_3.md` 为准。
